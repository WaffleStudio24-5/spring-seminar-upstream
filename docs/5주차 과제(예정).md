# 5주차 과제 (예정)

> 운영진 메모. 2026-11-08에 정한 내용만 적었습니다. 정식 과제 문서는 이후 따로 작성합니다.

## 결정 사항

1. **4주차 새 엔드포인트 3개는 `docs/4주차 과제.md` 명세대로 갑니다.**
   - `GET /seminars/{seminarId}/dashboard`
   - `PATCH /seminars/{seminarId}/enrollments/{enrollmentId}`
   - `PATCH /sessions/{sessionId}/records`
   - 수강 정보 수정에 `version`(낙관적 락)은 넣지 않습니다.
   - 최종 기준 구현과 프론트를 이 명세에 맞춰 고칩니다.

2. **남은 엔드포인트 3개는 5주차에 배포와 함께 구현합니다.**

   | 기능 | 메서드와 경로 |
   | --- | --- |
   | 회차 삭제 | `DELETE /sessions/{sessionId}` |
   | 내 정보 수정 | `PATCH /users/me` |
   | 회원 탈퇴 | `DELETE /users/me` |

   - 4주차 과제 문서의 "다음 주에 배포할 Waggle 서비스를 완성합니다"를 "나머지 기능은 5주차에 배포와 함께 마무리합니다"로 고쳤습니다.

## 5주차 명세에 담을 것

- **회원 탈퇴:** 사용자 상태 변경, 수강 신청 삭제, 출석·과제 기록 삭제를 한 트랜잭션으로 처리합니다. 탈퇴자의 로그인, 탈퇴 전에 받은 토큰, `GET /users` 목록과 대시보드에서의 표시, 같은 이메일 재가입 규칙도 정합니다.
- **회차 삭제:** 삭제할 수 있는 조건(마지막 회차이고 기록이 없을 때)과, 조건에 맞지 않을 때의 상태 코드를 정합니다.
- **내 정보 수정:** 고칠 수 있는 항목(이름, GitHub 사용자명)과 검증 규칙을 정합니다.
